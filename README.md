# ML-DNA-Disease-Risk
Know your files :
1) ML_report is the final report, satisfying the given criteria
2) final_dna_risk_project.ipynb is the main code file and you just have to run it.
3) synthetic_dna_dataset is the dataset we have used for this project.

How to use :
1) keep the dataset and ipynb files in the same folder
2) check the path in the first code cell
3) run all the cells and you will get the results.
